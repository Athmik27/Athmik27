##  About the Project

This is my personal developer portfolio, designed to present my technical skills, projects, educational background and interests in software development.

The website features a modern dark theme with gradient effects, smooth animations and a responsive layout.

It also integrates the GitHub REST API to automatically display my latest public repositories.

##  Features

- **Modern UI:** Eye-catching dark theme with blue and violet gradients.
- **Responsive Design:** Compatible with desktops, tablets and mobile devices.
- **Animated Hero Section:** Smooth animations and interactive visual elements.
- **About Me:** Introduction and professional background.
- **Skills Section:** Displays programming languages, libraries and technologies.
- **Dynamic GitHub Projects:** Automatically fetches public repositories using the GitHub API.
- **Education Section:** Showcases my academic journey.
- **Contact Section:** Provides links to GitHub, email and LinkedIn.
- **Smooth Navigation:** Easy navigation between different sections.

##  Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Athmik27/Athmik27.github.io.git
```

**2. Navigate to the project directory**

```bash
cd Athmik27.github.io
```

**3. Open the website**

Open `index.html` in your browser or use the VS Code Live Server extension.

##  GitHub Pages Deployment

You can host this portfolio for free using GitHub Pages.

1. Create a repository named `Athmik27.github.io`.
2. Upload your portfolio HTML file.
3. Rename `athmik-portfolio.html` to `index.html`.
4. Push the files to the `main` branch.
5. Navigate to **Settings → Pages**.
6. Select the `main` branch and `/root` folder.
7. Save your settings.

Your portfolio will be available at:

**https://athmik27.github.io/**
